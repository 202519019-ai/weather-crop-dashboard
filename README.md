
# Weather & Crop Prediction Dashboard - Demo

## Features
- Select location from 10 points in Jhabua district
- View current temperature, humidity, rainfall
- Get recommended crop based on weather
- 15-day forecast of temperature and rainfall

## Requirements
- Python 3.8+
- streamlit
- pandas
- numpy
- matplotlib
- requests

## How to Run
```bash
pip install -r requirements.txt
streamlit run app.py
